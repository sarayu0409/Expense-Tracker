# Expense-Tracker
A simple Expense Tracker web application built using HTML, CSS, JavaScript and Local Storage. Developed using Visual Studio Code

## Project Overview
Expense Tracker is a simple web application developed to help users manage their daily income and expenses. 
The application allows users to add, edit, delete, and track their transactions easily.

## Features
- Add income and expense transactions
- Edit existing transactions
- Delete transactions
- Calculate total balance
- Display income, expenses, and remaining balance
- Store data using Browser Local Storage
- Simple and user-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage

## Development Tools
- Visual Studio Code
- Git & GitHub

## How It Works
This application uses JavaScript and Browser Local Storage to store transaction data locally. 
The data remains available even after refreshing the browser.
